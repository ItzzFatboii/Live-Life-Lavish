LIVE. LIFE. LAVISH — FINAL WEBSITE PACKAGE

This package is prepared as the clean upload version for a static website.

IMPORTANT
- Do not edit the logo artwork.
- Product photography is intentionally not included in the collection yet.
- The premium editorial imagery supplied with the original site is retained.
- The mobile hero uses the original hero artwork at its natural ratio so it is not vertically stretched.
- The random Instagram link in the top header has been removed.
- Ordering buttons are set to the brand's Instagram DM link and the supplied Facebook link.
- No product prices are displayed.

ADDING PRODUCTS LATER
1. Put each finished product photo into images/products/.
2. Open products.js.
3. Add a product entry using the example already in that file.
4. Upload the new image and products.js. The website design itself does not need to be rebuilt.

Example entry:
{
  name: "LIVE. LIFE. LAVISH T-SHIRT",
  type: "T-SHIRT",
  description: "Black · S–XXXL",
  image: "images/products/tshirt-black.jpg",
  tag: "NEW"
}

The product section automatically changes from the placeholder to the product grid when at least one product is added.
